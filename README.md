# Maestro — AI Marketing Intelligence Platform

## Mosaic Wellness Fellowship 2026 Application
**Applicant:** Khushi Sharma

Maestro is a competitive advertising intelligence platform designed to outperform competitors in the wellness space. It analyzes Meta Ads Library data from brands like Mamaearth, Wellbeing Nutrition, and Oziva to generate strategic insights for Mosaic Wellness brands (ManMatters, BeBodywise, Little Joys).

## 🧠 Powered by Aria
Aria is the AI strategist inside Maestro. She behaves like a senior growth analyst, detecting creative patterns, identifying whitespace opportunities, and generating weekly strategy briefs.

### Key Features:
- **Creative Territory Map:** Visualizes market saturation and identifies "Open Territories" for new campaigns.
- **Weekly Intelligence Brief:** Automated strategic memos summarizing competitor movements and scaling ads.
- **Aria AI Chat:** A real-time interface to query the competitive dataset for specific growth insights.
- **Pattern Detection:** Identifies winning creative formulas (Hooks, Formats, Messaging) across the competitor set.

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Motion (Framer Motion), Lucide Icons.
- **Backend:** Node.js, Express.
- **AI:** Google Gemini 3.1 Pro via `@google/genai`.
- **Styling:** Premium "Apple-inspired" aesthetic with SF Pro typography and dynamic Aurora animations.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Set Environment Variables
Create a `.env` file in the root directory and add your Gemini API Key:
```env
GEMINI_API_KEY=your_api_key_here
```

### 3. Run the Development Server
```bash
npm run dev
```
